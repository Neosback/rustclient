# First-Party Plugins Scope

Rust ports of `RuneLite` plugins (see `docs/reference/builtin-plugins/` for the per-plugin ledger and
ADR-0006 for the API they run on). One module per plugin.

- Plugins observe immutable plugin API 0.2 snapshots/events and return declarative `PluginOutput`; they
  never touch `GameState`, the renderer or the platform.
- Configuration keys are the source `keyName`s from `crates/plugin-host/src/first-party-schemas.json`
  (generated by `tools/builtin-plugins/first_party_schemas.py`); read them through `PluginCall::config`.
- A fact the client does not retain yet reads as absent; never guess it. Record the gap in the ledger.
- Ported source files and resources keep their `RuneLite` BSD-2 notice (`NOTICE`).
- Keep the crate wasm-compatible: no filesystem, threads or platform APIs.
