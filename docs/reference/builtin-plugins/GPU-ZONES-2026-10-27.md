## Rust ownership and data flow

`scene::RelatedMaps` builds the normal-map chunk mask once with the immutable scene asset. One
`DrawTile` record is baked into every vertex of a terrain primitive or whole model. It contains two
signed ten-bit local tile coordinates and unrelated/outside flags. Temporary actor models are
independent of scenery deletion. Lighting, normals, shadows, collision, pathfinding and GameState
are unaffected. Toggling hideUnrelatedMaps uses the retained geometry and changes visibility at the
next frame; it needs no cache reload or second scene.

`SceneVisibility` now owns the former roof visibility plus an optional `ZoneWindow` and related-map
switch. Native render, terrain/object picking, hovered-roof queries, overhead speech and world plugin
overlays use the same frame admission. The renderer's vertex shader uses its supplied zone bounds;
standalone capture derives them after camera zoom/viewport/DPI shaping. Whole models share their
anchor, so the cut does not slice their triangles. Resource validation rejects inconsistent primitive/
model anchors. CPU geometry remains available for rebuilding and semantic queries.

The packed vertex grows from 20 to 24 bytes, adding one Uint32 attribute at offset 20. The WGSL/Rust
camera block grows from 640 to 672 bytes (zone bounds at 640, admission flags at 656); portable Naga
layout validation covers it. The 1,929,774-vertex spawn capture uses 46,314,576 vertex bytes, an increase
of 7,719,096 bytes. This implementation rejects vertices before rasterization; it does not yet reduce
CPU face sorting, uploads or draw-call submission. No performance improvement is claimed.

`RelatedMaps::for_instance` is an explicit bypass with a tested contract. The existing application
loader rejects `InitialPlacement.area.is_some()` before normal-map assembly. Instance-template travel
and its future bypass wiring remain incomplete; no normal-map classification is inferred for an
unsupported instance. Minimap/source callback side effects still require exact runtime acceptance.
